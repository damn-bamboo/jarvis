# J.A.R.V.I.S. — голосовой ассистент для Windows

Ассистент в духе Джарвиса из «Железного человека»: слушает микрофон, понимает русскую речь,
отвечает голосом и выполняет команды:

| Команда (говорить после «Джарвис») | Что делает |
|---|---|
| `запусти ворд / блокнот / калькулятор / <имя>` | Запускает программу из списка `config.json` (или ярлык из меню Пуск) |
| `напиши в ворде <текст>` | Печатает продиктованный текст в открытый Microsoft Word (через COM; если Word нет — печатает клавиатурой в активное окно) |
| `перемотай видео вперёд / назад`, `перемотай на 30 секунд / на минуту` | Переключается на окно плеера (VLC, PotPlayer, MPC…) и шлёт клавиши перемотки; в браузере (YouTube/VK-видео) работают те же ← → |
| `включи <исполнитель название трека>` | Ищет трек в **Яндекс Музыке**; нашёл — открывает страницу трека; не нашёл — открывает **поиск трека ВКонтакте** (всё во встроенном браузере интерфейса) |
| `пауза` / `продолжи` / `следующий трек` / `предыдущий трек` | Мультимедийные клавиши — управляют любым плеером/сайтом |
| `громче` / `тише` / `без звука` | Регулировка системной громкости |
| `выключи компьютер` | Отложенное выключение (15 с) с возможностью передумать: `отмена` |
| `перезагрузи компьютер` | Перезагрузка |
| `который час` / `какое сегодня число` | Ответ голосом |
| `пока` / `спокойной ночи` | Ассистент «засыпает» до следующего «Джарвис» |

Активация — словом **«Джарвис»** (меняется в настройках). После активации 8 секунд идёт
непрерывное распознавание — команды можно давать без повтора активатора.

## Быстрый старт (Windows) — всего два двойных клика

> ⚠️ Важно: файлы `.py` — это **обычный текст на языке Python**, а не «машинный код».
> Двойным кликом по ним Windows их не запускает (открывает блокнот). Запускать
> нужно **.bat-файлы** из папки проекта — они сделают всё сами.

1. Установите [Python 3.10+](https://www.python.org/downloads/)
   (на первом шаге установки обязательно отметьте галочку **Add python.exe to PATH**).
2. Дважды щёлкните по файлу **`setup.bat`** — он сам установит все библиотеки
   (нужен интернет, занимает 3–5 минут; если возникнет вопрос «Разрешить приложению
   вносить изменения?» — нажмите «Да»).
3. Дважды щёлкните по файлу **`start.bat`** — откроется окно Джарвиса
   (при первом запуске создастся файл настроек `config.json`).
4. Скажите: **«Джарвис, который час»** 🎉

Полезные режимы (запускать из папки проекта, в адресной строке папки наберите `cmd`):
```bat
python gui.py --list-voices   :: посмотреть доступные голоса системы
python gui.py --text-only     :: интерфейс без микрофона, команды печатаются текстом
python main.py --demo         :: проверить разбор команд в консоли (без установки библиотек!)
```

### Частые проблемы

| Симптом | Решение |
|---|---|
| Windows не запускает `gui.py`, открывает его в блокноте / «есть части машинного кода» | Это нормально: `.py` — исходный текст, а не программа. Запускайте **`start.bat`** (установка — **`setup.bat`**) |
| `setup.bat`: «Python ne nayden» | Установите Python с python.org и отметьте *Add python.exe to PATH*, затем повторите |
| Ошибка `No module named 'PyQt6'` и т.п. | Вы не запустили `setup.bat` (или установка прервалась) — повторите |
| `pyaudio` не устанавливается | `setup.bat` сам пробует запасной способ (`pipwin`). Если и он не помог: скачайте готовый `.whl` для своей версии Python с https://pypi.org/project/PyAudio/#files и выполните `pip install имя_файла.whl` |
| Окно появляется и сразу закрывается | Запустите `start.bat` — он оставит окно консоли с текстом ошибки; пришлите/прочитайте эту ошибку |
| Нет реакции на голос | Проверьте микрофон в настройках Windows; попробуйте режим `python gui.py --text-only` — если команды с клавиатуры работают, проблема только в микрофоне/распознавании |

## Настройка (всё кастомизируется без правки кода)

Файл **`config.json`** (создаётся автоматически):

* `voice.name` — имя голоса; `rate` — скорость; `volume` — громкость.
* `speech.keyword` — слово-активатор (например «компьютер»).
* `programs` — словарь «как называть -> что запускать». Добавьте свои программы:
  ```json
  "photoshop": "C:\\Program Files\\Adobe\\Photoshop\\Photoshop.exe"
  ```
* `shutdown.delay_seconds` — задержка выключения.
* `seek.step_seconds` — шаг перемотки.

Часть настроек доступна прямо в окне: кнопка **⚙ Настройки**.

### Как получить голос как у Джарвиса

1. **Вариант «настоящий Джарвис»:** скачайте бесплатный русский голосовой пакет
   *Jarvis* с сайта [NeoVoice](https://neovoice.ru/voices/program_neovoice/) (SAPI5,
   установится в систему), затем в ⚙ Настройки выберите его в списке «Голос»
   (или `python gui.py --list-voices` и пропишите имя в `config.json`).
2. **Быстрый вариант:** установите английский мужской голос *Microsoft David*
   (Параметры → Время и язык → Речь) — он уже звучит «технологично», а скорость/тон
   регулируются ползунками.
3. Синтез работает полностью офлайн (движок SAPI5 через `pyttsx3`).

## Как это устроено

```
gui.py            — интерфейс PyQt6: реактор-анимация, лента диалога, браузер, настройки
main.py           — консольный режим без GUI (+ демо разбора команд)
jarvis/
  assistant.py    — «мозг»: потоки слушания и выполнения, маршрутизация команд
  listener.py     — SpeechRecognition + Google Web Speech (русский язык, бесплатно)
  parser.py       — разбор фраз на команды (легко добавить свои regex-правила)
  actions.py      — запуск программ, диктовка в Word (COM), выключение ПК, перемотка
  music.py        — поиск трека: Яндекс Музыка -> fallback ВКонтакте
  voice.py        — озвучка pyttsx3 (SAPI5)
  config.py       — загрузка/сохранение config.json
```

Поток: микрофон → текст → проверка слова-активатора → `parser.parse()` →
`actions/music` → ответ текстом + голосом; ссылки на треки открываются во встроенном браузере.

## Важные замечания

* **Яндекс Музыка**: десктоп-приложение не имеет внешнего API управления, поэтому
  ассистент проверяет наличие трека через веб-поиск Яндекса и открывает найденную
  страницу во встроенном браузере (логика «нет в ЯМ → искать в ВК» реализована в
  `music.resolve_track`). При желании подключите официальный Яндекс.Музыка API с OAuth.
* **Перемотка в браузере** работает, когда вкладка с видео активна (интерфейс сам
  переключает её при команде).
* **Выключение** всегда с задержкой и отменой — случайная фраза компьютер не выключит.
* Распознавание речи через Google требует интернет. Офлайн-вариант: `pip install vosk`
  и замена `recognize_google` на `recognize_vosk` в `listener.py` (модель `vosk-model-small-ru`).

## Идеи для развития

* Перевод ответа в английский + голос Jarvis для полного «киношного» звучания.
* Large Language Model (локальная Ollama или API) вместо regex-парсера для свободных фраз.
* Плавающее окно-«реактор» поверх всех окон, сворачивание в трей.
* Голосовой набор текста в любую программу (режим «диктовка до слова „стоп“»).
